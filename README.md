# Slider Design V2

Camera slider project with 3D printed parts, Arduino control, and Windows controller.

## Project Structure

- `3d_models/` - STL files for 3D printed slider components
- `firmware/` - Arduino sketch files for slider control
- `controller/` - Windows desktop controller application

## Components

### 3D Models
- `2040_slider_carriage_bottomV1.stl`
- `2040_slider_carriage_topV1.stl`
- `CameraUplateV1.stl`
- `Carriage_Base_V1.stl`
- `PanAxisCarriageV1.stl`

### Firmware
- Arduino Network Slider PTZ control
- CHATGPT Arduino Mega Code with NRF24

### Controller
- Windows Controller Python application
